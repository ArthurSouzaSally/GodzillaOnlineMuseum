# GodzillaOnlineMuseum
Online Godzilla Fan Museum

This is a university project I did, sort of my version of the Godzilla museum. The website is navigable and available for free; anyone interested can simply browse it. It's a design project, so I focused less on the narrative and more on the design of the monsters/movie posters.
